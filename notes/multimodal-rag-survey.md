## 一句话总结
这篇综述的核心价值是 **把多模态 RAG 从一个模糊的概念，拆解成了检索→融合→增强→生成四个可独立分析的技术阶段**，并在每个阶段系统整理了主流方法、代表工作和设计取舍。它不是只聚焦某一个模态或某一个任务，而是覆盖了文本、图像、视频、音频和文档五大模态的检索策略，三类融合机制（分数对齐、注意力、统一投影），两大增强范式（上下文丰富与自适应迭代），以及四种生成技术（ICL、推理链、指令微调、Agent），为理解和构建多模态 RAG 系统提供了最完整的技术地图。

## 背景：为什么需要多模态 RAG？

传统 RAG 已经在文本领域证明了价值——通过检索外部知识来弥补 LLM 的知识截止和幻觉问题。但现实世界的信息远不只是文本：医学报告包含影像，产品文档有示意图，教育内容包含视频和音频，社交媒体是图文混合流。

**单模态 RAG 的三个核心限制**：
- **信息丢失**：把图表转成 caption、把视频压缩成文本摘要，必然损失细粒度视觉和时序信息
- **模态偏置**：检索和生成通常过度依赖文本，忽视视觉证据的判别力
- **跨模态推理缺失**：答案可能需要同时整合文本段落中的数值和图表中的趋势，单模态 pipeline 无法做到

多模态 RAG 要解决的不只是"让 RAG 支持图片输入"，而是构建一个能够 **在异构模态之间检索、对齐、推理和生成** 的统一系统。

## 方法总览：四阶段技术栈

论文把多模态 RAG 的技术栈分成四个核心阶段，每个阶段有独立的设计空间和取舍：

### 阶段一：多模态检索

检索是 RAG 的入口。论文按模态将检索策略分为四类：

#### 1. 文本中心检索
最成熟的一类，利用文本表征从知识库中检索相关信息。代表方法包括：
- **稀疏检索**：BM25、TF-IDF 等传统方法，用于初筛
- **密集检索**：基于 BERT/Sentence Transformer 的语义向量检索
- **混合检索**：将稀疏和密集信号结合，如 RAFT 通过训练检索器学会忽略干扰文档来提升鲁棒性；CRAG 通过确保文本跨度的准确引用来增强检索

#### 2. 视觉中心检索
利用图像表征进行知识提取。主要方向包括：
- **以图搜图**：EchoSight、ImgRet 等系统用参考图像作为 query 检索视觉相似内容
- **组合图像检索**：将多个图像特征整合为统一 query 表征，实现零样本图像检索
- **跨模态检索**：在 CLIP 等共享嵌入空间中做文本到图像或图像到文本的检索

#### 3. 视频中心检索
在视觉检索基础上引入时序动态：
- **增量检索**：iRAG 实现视频序列的增量式检索，保持时序连贯
- **长上下文处理**：Video-RAG 使用辅助 OCR/ASR 文本避免依赖私有模型；VideoRAG 用双通道架构和图知识锚定处理超长视频
- **时序推理**：CTCH 用对比 Transformer 哈希捕获长程依赖；RTime 引入反向视频困难负例增强因果性
- **复杂理解**：OmAgent 用分治框架处理复杂视频；DRVideo 用文档中心方法增强叙事保持

#### 4. 音频中心检索
绕过传统 ASR 管线，直接在音频空间检索：
- **统一嵌入**：WavRAG、SEAL 直接将原始音频映射到共享潜空间，从混合知识库中检索
- **音频生成增强**：Audiobox TTA-RAG 在文本到音频合成中基于检索的声学样本调节生成
- **错误纠正**：LA-RAG 通过细粒度语音到语音检索和强制对齐增强 ASR 准确率

#### 5. 文档检索与版面理解
超越单模态，将文本、视觉和版面信息整合处理：
- **端到端文档图像检索**：ColPali 用视觉语言主干嵌入页面补丁，完全绕过 OCR
- **动态分辨率**：ColQwen2、M3DocVQA 处理多页文档的动态分辨率推理
- **版面对齐**：ViTLP、DocLLM 预训练生成模型将空间版面与文本对齐
- **粗到细检索**：CREAM 用多模态高效微调平衡准确率和计算成本

#### 重排序与选择策略
检索后的优化同样关键：
- **优化样例选择**：多步检索、监督/无监督选择结合；RULE 用 Bonferroni 校正校准检索上下文以降低事实性风险
- **评分机制**：SSIM、NCC、BERTScore 等多模态相似度度量；VR-RAG 结合跨模态文本-图像相似度和模态内视觉相似度
- **过滤方法**：GME、MM-Embed 通过模态感知采样和合成负例缓解模态偏置；动态模态过滤如 MAIN-RAG 训练检索器忽略干扰数据

### 阶段二：多模态融合

检索到多模态证据后，如何将它们融合为统一表征是核心挑战。论文归纳出三类融合机制：

#### 1. 分数融合与对齐
将不同模态的相似度分数或表征在共享空间中对齐：
- **CLIP 空间对齐**：Wiki-LLaVA、C3Net、MegaPairs 将图像和文本嵌入到共享 CLIP 空间。MegaPairs 进一步融合 CLIP 和 MLLM 检索分数，利用互补优势，但增加推理复杂度
- **检索分数注入**：REVEAL 将检索分数注入注意力层，最小化 query 与知识嵌入的 L2 范数差异
- **位置加权池化**：VISRAG 对 VLM 隐藏状态应用位置加权均值池化，给后续 token 更高权重
- **创意-保真平衡**：Re-IMAGEN 在扩散采样中通过交错无分类器引导，平衡文本到图像合成的创意性和实体保真度

#### 2. 注意力融合
通过动态跨模态注意力实现细粒度交互：
- **交叉注意力**：EMERGE、MORE、AlzheimerRAG 用跨注意力集成异构模态，但通常需要任务特定的注意力头
- **双流共注意力**：RAMM 结合自注意力和交叉注意力融合检索的生物医学图文数据
- **辅助 caption 引导**：M2-RAAP 用 caption 引导策略重加权帧和文本，再用互引导对齐头过滤不匹配特征
- **门控交叉注意力**：条件化文本生成于视觉特征，优化可控性

#### 3. 统一框架与投影
将多模态输入整合为连贯的统一表征：
- **文档展平**：M3DocRAG 将多页文档展平为单一嵌入张量
- **联合粒度检索**：PDF-MVQA 融合粗粒度语义实体表征与细粒度 token 级文本内容
- **模态统一**：DQU-CIR 对复杂查询将图像转文本 caption，对简单查询将文本叠加到图像上，再用 MLP 学习权重融合嵌入
- **Dense2Sparse 投影**：将 BLIP/ALBEF 的密集嵌入转换为稀疏词法向量，优化存储和可解释性

### 阶段三：增强技术

基础 RAG 通常单步检索直接送生成，增强技术在检索和生成之间加入优化环节：

#### 1. 上下文丰富
- **实体关系扩展**：EMERGE 通过集成实体关系和语义描述丰富上下文
- **查询分解**：Video-RAG 通过 Query Decoupling 将用户查询重构为结构化检索请求
- **正反样例提示**：Img2Loc 在提示中同时包含相似和不相似地点，帮助排除不合理位置

#### 2. 自适应与迭代检索
- **动态路由**：UniversalRAG 根据 query 所需模态和粒度（段落 vs 文档，片段 vs 完整视频）动态路由到最合适的语料库
- **知识需求评估**：SAM-RAG、mR²AG 动态评估是否需要外部知识，用 MLLM 过滤无关内容
- **多步粗到细**：OMGM 从广泛实体搜索开始，逐步通过多模态重排序和细粒度文本过滤精炼
- **迭代更新**：IRAMIG 基于已检索内容动态更新查询；OMG-QA 集成情景记忆跨轮次精炼

### 阶段四：生成技术

#### 1. 上下文学习（ICL）
将检索内容作为少样本示例，无需重训练：
- RAG-Driver 从记忆数据库检索相关驾驶经验作为上下文
- MSIER 用 MLLM 评分器评估文本和视觉相关性优化样例选择
- Raven 引入 Fusion-in-Context Learning，整合多样化上下文示例

#### 2. 推理链
将复杂推理分解为序列化步骤：
- **RAG 链与 RAG 树**：RAGAR 引入 Chain of RAG 和 Tree of RAG，精炼事实核查查询并探索分支推理路径
- **多阶段验证**：VisDoM、SAM-RAG 将 CoT 与证据管理和多阶段验证结合，在信息分布于多模态时表现尤佳
- **发散组合推理**：LDRE 用 LLM 精炼 caption 的密集描述和文本修改，实现零样本组合图像检索

#### 3. 指令微调
针对特定应用微调生成组件：
- RA-BLIP 利用 InstructBLIP 的 Q-Former 架构基于问题指令提取视觉特征
- MMed-RAG 通过偏好微调帮助模型平衡检索知识与内部推理
- MegaPairs、Surf 从 LLM 先前错误构建多模态指令微调数据集

#### 4. Agent 驱动生成
自主/半自主系统跨领域的多样化交互：
- **用户交互**：AppAgent v2 实现移动 GUI 导航；USER-LLM R1 通过动态画像创建个性化对话 Agent
- **专业应用**：MMAD 处理工业异常检测；CollEX 促进科学收藏探索
- **层级多 Agent 协作**：HM-RAG 协调跨多模态数据流的层级多 Agent 协作
- **认知规划**：CogPlanner 引入认知启发的规划框架，迭代精炼查询并自适应选择检索策略

## 训练策略

多模态 RAG 模型的训练通常遵循多阶段流程：

### 预训练 + 微调
- **预训练阶段**：在大规模配对数据上建立跨模态关系。如 REVEAL 同时优化前缀语言建模损失、对比损失、去纠缠正则化损失和对齐正则化损失
- **微调阶段**：用交叉熵等目标适配下游任务（VQA、图像描述等）

### 对齐训练
对比学习是多模态 RAG 中最常用的对齐手段：
- **InfoNCE 损失**：VISRAG、MegaPairs、SAM-RAG 广泛使用，拉近正样本、推开负样本
- **困难负例挖掘**：EchoSight 选择视觉相似但语义不同的负例；HACL 引入对抗性 caption 作为干扰项
- **eCLIP 损失**：扩展对比学习，整合专家标注数据和辅助 MSE 损失
- **稀疏正则化**：Dense2Sparse 用 L1 正则化在密集和稀疏表征之间取得平衡

## 开放问题与未来方向

### 1. 泛化性、可解释性与鲁棒性
- 多模态 RAG 存在显著的 **模态偏置**，检索和生成通常过度依赖文本
- **可解释性不足**：系统往往引用整篇文档或大面积视觉区域，而非定位具体贡献元素
- **对抗脆弱性**：MM-PoisonRAG、Poisoned-MRAG 证明少量对抗知识注入即可劫持跨模态检索和生成
- 与单模态 RAG 的可信度研究相比，多模态 RAG 的鲁棒性研究仍是空白

### 2. 推理、对齐与检索增强
- **组合推理**仍然困难：需要跨模态逻辑整合信息以生成连贯输出
- **知识图谱**在多模态 RAG 中的应用远少于文本 RAG，潜力待挖掘
- 检索偏置包括 **位置敏感性**、冗余和训练数据偏差
- **统一嵌入空间**是最有前景的方向之一：让所有模态在同一空间中直接检索，无需中间模型（如 ASR）

### 3. Agent 化与自引导系统
- 未来系统应从静态 RAG 转向 **交互式反馈和自引导决策**
- **强化学习和端到端人类对齐反馈**在多模态 RAG 中几乎未被探索，但有重大潜力
- 需要支持 **任意到任意模态** 的开放式任务
- 最终趋势是走向 **具身 AI**：将检索推理与物理交互结合，实现机器人、导航和物理推理

## 我的理解与启发

这篇综述最大的贡献是提供了一张 **多模态 RAG 的完整技术地图**。读完之后，有几个关键洞察：

### 多模态 RAG 不是"RAG + 多模态"的简单叠加
传统 RAG 的 pipeline（检索→拼接→生成）在多模态场景下每个环节都需要重新设计。检索不只是向量相似度，还要考虑模态特定的语义（视频的时序、音频的声学特征、文档的版面）；融合不只是拼接，还要处理模态间的粒度差异和语义鸿沟；生成不只是续写，还要判断何时该引用视觉证据、何时该依赖文本。

### 融合是最关键也最未解决的环节
三类融合机制各有局限：分数融合简单但丢失细粒度交互；注意力融合灵活但计算量大且需要任务特定设计；统一投影优雅但可能在投影过程中损失模态特异性信息。目前没有一种融合策略能在所有场景下最优，这是最值得投入的研究方向。

### Agent 化是多模态 RAG 的演化终点
从单步检索到迭代检索，从固定 pipeline 到动态路由，从被动生成到主动推理——多模态 RAG 正在从"工具"演化为"Agent"。HM-RAG 的层级多 Agent 协作和 CogPlanner 的认知启发规划已经在探索这个方向。

### 对工程实践的启示
- **不要一步到位**：先用文本中心检索 + caption 代理建立基线，再逐步引入视觉检索和端到端融合
- **重排序比检索本身更重要**：多模态场景下初始检索的噪声更大，好的重排序策略（如 VR-RAG 的视觉重排序）能显著提升最终效果
- **评估要覆盖多模态**：不能只用文本 QA 指标，需要加入视觉定位准确率、跨模态一致性和源归因质量

## 局限与待观察点
- **缺少定量比较**：综述没有对各方法做统一 benchmark 下的性能对比，读者难以判断具体方法的优劣
- **快速演化**：论文截止到 2025 年初，多模态 RAG 领域发展极快，新范式（如视觉原生 RAG、长视频 RAG）可能已改变格局
- **工程可行性讨论不足**：许多方法的计算成本、延迟和部署约束未充分分析
- **评估标准碎片化**：不同任务、不同模态的评估指标差异很大，缺少统一评估框架

## 结论
这篇综述为多模态 RAG 提供了目前最全面的技术分类体系。它的四阶段框架（检索→融合→增强→生成）为理解和设计多模态 RAG 系统提供了清晰的思维脚手架。更重要的是，它指出了这个领域最关键的几个开放问题：统一多模态嵌入空间、跨模态组合推理、对抗鲁棒性和 Agent 化系统。对于正在构建多模态知识系统的工程师和研究者，这篇综述是一个很好的起点和参考地图。
